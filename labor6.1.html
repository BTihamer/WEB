Labor: Vue.js + Firebase + Cloud Functions – Weather App

3. évfolyam – gyakorlati projekt: frontend (Vue 3), backend proxy (Firebase Functions), hosting és opcionális adatkezelés (Firestore)

🎯 Cél

Készítsetek egy egyszerű, de teljes értékű időjárás-alkalmazást, amely Vue 3-at használ a felületen, a külső időjárás API-t pedig Firebase Cloud Function hívja meg (proxy + kulcs elrejtése). Az appot Firebase Hostingon publikáljátok, opcionálisan a keresési előzményeket Firestore-ban tároljátok.

Vue 3 Axios Firebase Hosting Cloud Functions (Node.js) Firestore (opcionális)

🧩 Követelmények

Frontend

  • Vue 3
  • Axios a HTTP kérésekhez
  • Reszponzív UI, input (város), gomb, kártya

Backend / Serverless

  • Firebase Cloud Functions (HTTPS endpoint)
  • Function hívja a publikus weather API-t (pl. OpenWeatherMap)
  • API kulcs titokban: functions.config()

Hosting / DB (opcionális)

  • Firebase Hosting a Vue apphoz
  • Firestore: utolsó keresések / kedvencek

Megjegyzés: más időjárás API is használható (pl. WeatherAPI), a lényeg, hogy a kulcs a felhőben maradjon, és a frontend csak a Functiont hívja.

⚙️ Lépésről lépésre

1) Alap Vue 3 projekt

# Projekt létrehozása
        npm create vue@latest weather-app
        cd weather-app
        npm install
        npm run dev

# Fejlesztő szerver
npm run dev

2) Firebase beállítás és Hosting

# Firebase CLI telepítés
npm install -g firebase-tools
firebase login
firebase init

3) Cloud Function (proxy az API felé)

const functions = require("firebase-functions");
const axios = require("axios");

exports.getWeather = functions.https.onRequest(async (req, res) => {
  res.set("Access-Control-Allow-Origin", "*");
  const city = req.query.city;
  const apiKey = functions.config().weather.key;
  const url = \`https://api.openweathermap.org/data/2.5/weather?q=\${city}&units=metric&appid=\${apiKey}\`;

  try {
    const { data } = await axios.get(url);
    res.json(data);
  } catch (error) {
    res.status(500).send(error.message);
  }
});

🚀 Deploy – éles környezetbe helyezés

Ha minden működik lokálisan az emulátorban, jöhet a projekt publikálása a Firebase szervereire.

1️⃣ Build és deploy parancsok

# Frontend buildelése (Vite)
      npm run build
      
      # Feltöltés a Firebase-re
      firebase deploy

A deploy végén a konzolban megkapod az URL-eket:

  • Hosting URL: pl. https://myproject.web.app
  • Function URL: pl. https://us-central1-myproject.cloudfunctions.net/getWeather

2️⃣ Beállítások ellenőrzése

  • Győződj meg róla, hogy a firebase.json tartalmazza a megfelelő rewrites-t:
{
        "hosting": {
          "public": "dist",
          "ignore": ["firebase.json", "**/.*", "**/node_modules/**"],
          "rewrites": [
            { "source": "/api/**", "function": "getWeather" },
            { "source": "**", "destination": "/index.html" }
          ]
        }
      }

3️⃣ API kulcs biztonság

Az OpenWeatherMap API kulcs soha ne legyen a frontend kódban. Tárold a Cloud Function configban:

firebase functions:config:set weather.key="IDE_AZ_API_KEY"
      firebase deploy --only functions

Ezzel az API kulcs a Google Cloud környezetében biztonságosan elérhető lesz, és a hallgatók sem tudják kiszivárogtatni.

4️⃣ Tesztelés

A deploy után próbáld ki a Function-t közvetlenül a böngészőből vagy Postmanből:

https://us-central1-<PROJECT_ID>.cloudfunctions.net/getWeather?city=Budapest
